# Listing批量差异化裂变系统

## 解决什么问题
跨境商家批量铺品或运营店群时，手动复制商品和多变体耗时极长。且直接复制会导致商品标题、首图完全雷同，不仅缺乏 SEO 差异化权重，还极易触发平台的重复铺货惩罚。

## 核心功能
- **任意数量无感裂变**：选中商品 ID 即可一键生成多份防关联副本，支持同步保留所有变体结构。
- **SEO 标题差异化**：自动关联独立标题池，裂变时批量替换新标题，实现单品防重。
- **首图随机去重算法**：80% 概率自动在主图与轮播图间进行整块对调，确保商品视觉差异。
- **重量格式智能保护**：自动重置重量为标准双位小数并锁定文本格式，规避平台批量上传报错。

## 使用方式
1. 打开包含源数据的 Google Sheets 表格。
2. 框选需要裂变的商品 ID 区域。
3. 运行扩展菜单中的脚本，在弹窗中输入需要的副本数量，3~5秒内自动在专属标签页生成纯净数据。

## 技术实现
- Google Apps Script (JavaScript ES6)
- 内存数组批量操作（摒弃逐行写表，彻底解决大数据量超时崩溃问题）
- 自学 Vibe coding 全链路开发优化

## 业务价值
- **生产力降维打击**：将传统人工差异化复制的单品耗时（超2分钟）缩短至毫秒级，实现规模化裂变。
- **安全安全与合规**：全自动完成主图防重与标题池轮换，降低店群铺货的合规风险，提升搜索权重。
