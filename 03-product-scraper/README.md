# 汽摩配商品信息自动抓取插件（分前端版/shopee后台版）

## 解决什么问题
选品时缺少站外竞品数据支撑。手动复制粘贴商品标题、图片、详情效率极低，且容易遗漏关键信息。

## 核心功能
- 一键抓取网页上的商品标题、图片、商详描述
- 自动整理为结构化数据，可导出至Excel
- 支持批量抓取，覆盖多个竞品店铺

## 使用方式
1. 安装 Tampermonkey 浏览器插件
2. 导入本脚本
3. 打开目标商品页面，自动运行抓取

## 技术实现
- JavaScript (Tampermonkey API)
- 自学 Vibe coding 开发
- 纯浏览器端运行，不涉及隐私

## 业务价值
- 站外竞品数据快速获取，辅助选品决策
- 大幅降低手动调研时间成本
